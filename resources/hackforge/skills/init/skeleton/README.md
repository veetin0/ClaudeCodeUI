# challenge/ — drop everything here

HackForge reads this whole folder at kickoff. You don't need to type the brief into chat.

| Folder | Put here |
|---|---|
| `brief/` | The challenge brief, rules, judging rubric, FAQ, terms, organiser announcements (PDF, docs, screenshots, pasted Slack/Discord text as .md) |
| `data/` | Datasets, sample inputs, API docs, credentials *notes* (never real secrets — use `.env`) |
| `assets/` | Anything to build with or match: 3D models (.blend .glb .fbx .obj .stl), images, logos, brand guides, fonts, audio, video, CAD |
| `prompts/` | Your own instructions as .md files — priorities, ideas, style, "aim for the innovation prize". Each file becomes a team directive |
| `examples/` | Past winning entries, reference projects, inspiration, the sponsor's product docs |
| `hackforge.yaml` | Deadline, team size, effort profile, models, loop settings |

New files added mid-hackathon (e.g. an announcement) are picked up by `/hackforge:rules` or the next session.
